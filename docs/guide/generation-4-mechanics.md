# 第四世代机制变化（相较于第三世代）

本文以《红宝石／蓝宝石／绿宝石／火红／叶绿》为第三世代参照，整理第四世代尤其是《心金·魂银》的机制变化。对战、培育和传送规则不能直接使用第三世代或第五世代以后的攻略。

## 最重要的变化：物理／特殊分家

第三世代根据**招式属性**决定伤害类别；第四世代改为根据**每个招式自身**决定。物理招式使用攻击方的“攻击”和防守方的“防御”，特殊招式使用“特攻”和“特防”。

### 第三世代的分类方式

- 物理：一般、格斗、飞行、毒、地面、岩石、虫、幽灵、钢。
- 特殊：火、水、草、电、超能力、冰、龙、恶。

### 常见招式变化示例

| 招式 | 第三世代 | 第四世代《心金·魂银》 |
| ---- | ---- | ---- |
| 暗影球（シャドーボール / Shadow Ball） | 幽灵属性，因此为物理招式 | 特殊招式 |
| 叶刃（リーフブレード / Leaf Blade） | 草属性，因此为特殊招式 | 物理招式 |
| 咬碎（かみくだく / Crunch） | 恶属性，因此为特殊招式 | 物理招式 |
| 攀瀑（たきのぼり / Waterfall） | 水属性，因此为特殊招式 | 物理招式 |
| 破坏光线（はかいこうせん / Hyper Beam） | 一般属性，因此为物理招式 | 特殊招式 |

:::warning[查看招式时不能只看属性]
例如，高攻击的宝可梦在第四世代也能有效使用叶刃、咬碎等原本受属性分类限制的招式。组队时应直接查看招式详情中的“分类”。
:::

## 对战系统的其他变化

| 机制 | 第三世代 | 第四世代《心金·魂银》 |
| ---- | ---- | ---- |
| 场地与速度控制 | 没有第四世代新增的场地效果 | 新增隐形岩（ステルスロック / Stealth Rock）、毒菱（どくびし / Toxic Spikes）、戏法空间（トリックルーム / Trick Room）、顺风（おいかぜ / Tailwind）等 |
| 沙暴 | 造成持续伤害并影响部分特性 | 额外使岩石属性宝可梦的特防提高 50% |
| 对战道具 | 选择类强化道具较少 | 新增讲究头带（こだわりハチマキ / Choice Band）、讲究眼镜（こだわりメガネ / Choice Specs）、讲究围巾（こだわりスカーフ / Choice Scarf）、生命宝珠（いのちのたま / Life Orb）、气势披带（きあいのタスキ / Focus Sash）等 |
| 树果恢复 | 文柚果（オボンのみ / Sitrus Berry）固定恢复 30 点 HP | 改为恢复最大 HP 的 25% |
| 招式机器 | 50 个招式学习器与 8 个秘传学习器 | 92 个招式学习器与 8 个秘传学习器，共 100 个 |
| 特性 | 部分宝可梦拥有两种普通特性 | 新增多种特性，但没有第五世代才加入的隐藏特性 |

### 秘传学习器调整

《心金·魂银》仍然需要秘传学习器推进地图，但组成与第三世代不同：

- 闪光（フラッシュ / Flash）改为招式学习器 70，不再占用秘传学习器位置。
- 潜水（ダイビング / Dive）不在《心金·魂银》的秘传学习器列表中。
- 潮旋（うずしお / Whirlpool）与攀岩（ロッククライム / Rock Climb）成为秘传学习器。

## 培育与基础点数训练

### 孵化等级改为 1 级

第三世代的蛋孵化为 5 级；第四世代开始改为 1 级。这是第四世代精灵资料与第三世代资料常见的差异之一。

### 力量道具同时影响基础点数与个体值遗传

第四世代新增力量系列道具：

- 对战结束后额外增加对应项目的 **4 点基础点数**，不是第五世代以后的 8 点。
- 在《心金·魂银》中，父母持有力量道具时，可以确保对应项目的个体值遗传给子代。
- 强制锻炼器（きょうせいギプス / Macho Brace）仍然只是提高基础点数获取效率，不能用于固定遗传个体值。

### 不变之石的性格遗传扩大

第三世代通常由母方或与百变怪同行的一方携带不变之石（かわらずのいし / Everstone）来遗传性格；在《心金·魂银》中，**父母任意一方携带都有 50% 概率遗传其性格**。

### 国际婚姻提高异色概率

第四世代开始，来自不同现实语言地区的宝可梦培育时，子代异色概率从通常的 1/8192 提高至 5/8192，约为 1/1638。

注意：第四世代的国际婚姻与不变之石性格遗传不能同时生效，与后续世代不同。

:::warning[不要套用后世代培育规则]
红线（あかいいと / Destiny Knot）在《心金·魂银》中**不能**用于遗传父母双方的 5 项个体值。该效果是第六世代才加入的。
:::

## 地图与游戏系统变化

- **跨世代传送**：可通过伙伴公园把第三世代宝可梦传入《心金·魂银》，但属于单向传送，不能传回第三世代。
- **时间与日期**：昼夜、星期事件和时间限定遭遇重新成为重要系统，部分宝可梦、道具和 NPC 只在特定时间出现。
- **球果树与柑果球**：可使用不同球果制作等级球、月亮球、沉重球等第三世代没有的柑果球。
- **头锤撞树**：可对特定树木使用头锤，遭遇部分普通草丛中没有的宝可梦。
- **同行宝可梦**：队伍首只宝可梦会跟随主角，不同宝可梦拥有各自的跟随形象与反应。
- **宝可计步器**：通过随卡带附带的计步器外出积累步数，并获得宝可梦、道具和经验。
- **双屏与触摸操作**：利用 Nintendo DS 双屏显示菜单、地图和队伍信息，部分操作可直接触摸完成。

## 保持不变的基本规则

- 个体值仍为 0–31，基础点数总和上限仍为 510，单项有效上限仍为 252。
- 性格仍为 25 种，通常异色概率仍为 1/8192。
- 没有第六世代的妖精属性，钢属性仍然抵抗幽灵和恶属性招式。
- 没有隐藏特性，也没有红线遗传 5 项个体值的培育方式。
- 学习装置仍是让持有者分配经验的道具，不是后世代的全队经验共享开关。
