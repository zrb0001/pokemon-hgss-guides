# 所有精灵球介绍

《心金·魂银》共有 **25 种精灵球**：5 种基础与场地球、8 种钢铁先生与捕虫大赛相关的球、10 种特殊功能球，以及贵重球和伙伴公园球。本页效果均按第四世代机制整理，不混用后世代数值。

:::tip[捕获率说明]
“×N”表示捕获率倍率，不等于最终捕捉成功率。野生宝可梦的种类、当前 HP 与异常状态也会影响结果。大师球和伙伴公园球属于必定捕捉，不需要按倍率计算。
:::

## 基础与场地球

| 精灵球（日文 / English） | 第四世代效果 | 主要获得方式 |
| ---- | ---- | ---- |
| 精灵球（モンスターボール / Poké Ball） | 捕获率 ×1 | 各地宝可梦商店 |
| 超级球（スーパーボール / Great Ball） | 捕获率 ×1.5 | 各地宝可梦商店 |
| 高级球（ハイパーボール / Ultra Ball） | 捕获率 ×2 | 各地宝可梦商店，随剧情进度开放 |
| 大师球（マスターボール / Master Ball） | 必定捕捉野生宝可梦 | 集齐城都八枚徽章后，从空木博士处获得一个 |
| 狩猎球（サファリボール / Safari Ball） | 在狩猎地带中捕获率 ×1.5 | 进入城都狩猎地带时提供，只能在该设施使用 |

## 柑果球与竞赛球

击退呆呆兽之井的火箭队后，可把柑果交给桧皮镇的钢铁先生制作精灵球，每种柑果每天可加工一次。竞赛球则在捕虫大赛期间统一提供。

| 精灵球（日文 / English） | 第四世代效果 | 材料／获得方式 |
| ---- | ---- | ---- |
| 等级球（レベルボール / Level Ball） | 己方等级不高于对手时 ×1；更高但不足 2 倍时 ×2；达到 2 倍但不足 4 倍时 ×4；达到 4 倍时 ×8 | 红柑果（あかぼんぐり / Red Apricorn） |
| 诱饵球（ルアーボール / Lure Ball） | 对垂钓遇到的宝可梦 ×3，其他情况 ×1 | 蓝柑果（あおぼんぐり / Blu Apricorn） |
| 月亮球（ムーンボール / Moon Ball） | 对可用月之石（つきのいし / Moon Stone）进化的宝可梦及其进化家族 ×4，其他情况 ×1 | 黄柑果（きぼんぐり / Ylw Apricorn） |
| 友友球（フレンドボール / Friend Ball） | 捕获率 ×1；捕捉后亲密度直接设为 200 | 绿柑果（みどぼんぐり / Grn Apricorn） |
| 甜蜜球（ラブラブボール / Love Ball） | 与己方出战宝可梦种类相同且性别相反时 ×8，其他情况 ×1 | 粉柑果（ももぼんぐり / Pnk Apricorn） |
| 沉重球（ヘビーボール / Heavy Ball） | 按体重对原始捕获率加减：不足 100 kg 为 −20；100–199.9 kg 为 ±0；200–299.9 kg 为 +20；300 kg 以上为 +30 | 黑柑果（くろぼんぐり / Blk Apricorn） |
| 速度球（スピードボール / Fast Ball） | 目标速度种族值达到 100 时 ×4，其他情况 ×1 | 白柑果（しろぼんぐり / Wht Apricorn） |
| 竞赛球（コンペボール / Sport Ball） | 捕虫大赛中捕获率 ×1.5 | 参加捕虫大赛时提供 20 个，只能在比赛中使用 |

:::warning[沉重球不是倍率加成]
沉重球的数值是加减到宝可梦的原始捕获率上，并非乘算。对体重不足 100 kg 的目标可能反而更难捕捉。
:::

| ---- | ---- | ---- |
| 捕网球（ネットボール / Net Ball） | 对水或虫属性 ×3，其他情况 ×1；水／虫双属性不会重复叠加 | 桧皮、缘朱、烟墨、常青等地商店；满金百货抽奖周三二等奖 |
| 潜水球（ダイブボール / Dive Ball） | 在冲浪或垂钓遭遇中 ×3.5，其他情况 ×1 | 从《钻石／珍珠／白金》传入，或通过宝可计步器路线取得 |
| 巢穴球（ネストボール / Nest Ball） | 倍率为（40 − 目标等级）÷10，最低 ×1；1 级时 ×3.9，30 级起固定 ×1 | 深灰、枯叶与狩猎地带大门商店；满金百货抽奖周一二等奖 |
| 重复球（リピートボール / Repeat Ball） | 目标已登记为“已捕捉”时 ×3，其他情况 ×1 | 满金百货抽奖周二二等奖，或从《钻石／珍珠／白金》传入 |
| 计时球（タイマーボール / Timer Ball） | 第一回合 ×1，之后每经过一回合增加 0.1，经过 30 回合后达到最高 ×4 | 满金百货抽奖周六二等奖，或从《钻石／珍珠／白金》传入 |
| 豪华球（ゴージャスボール / Luxury Ball） | 捕获率 ×1；捕捉后，每次增加亲密度时额外 +1 | 满金百货抽奖周日二等奖，或从《钻石／珍珠／白金》传入 |
| 纪念球（プレミアボール / Premier Ball） | 捕获率 ×1，仅外观不同 | 在宝可梦商店一次购买 10 个精灵球时赠送 1 个 |
| 治愈球（ヒールボール / Heal Ball） | 捕获率 ×1；捕捉后立即恢复全部 HP、PP 并解除异常状态 | 从《钻石／珍珠／白金》传入，或通过宝可计步器路线取得 |
| 先机球（クイックボール / Quick Ball） | 战斗第一回合使用 ×4，之后 ×1 | 满金百货抽奖周四二等奖，或从《钻石／珍珠／白金》传入 |
| 黑暗球（ダークボール / Dusk Ball） | 在洞窟内或夜晚 ×3.5，其他情况 ×1 | 烟墨、枯叶、紫苑、浅红等地商店；满金百货抽奖周五二等奖 |

## 活动与联动专用球

| 精灵球（日文 / English） | 效果 | 使用范围 |
| ---- | ---- | ---- |
| 贵重球（プレシャスボール / Cherish Ball） | 捕获率 ×1，用于纪念特殊活动 | 通常只随活动赠送的宝可梦出现，不能作为普通消耗品在商店购买 |
| 公园球（パークボール / Park Ball） | 必定捕捉目标 | 只能在伙伴公园的跨世代传入过程中使用 |

## 选择建议

- **开场尝试捕捉**：先机球在第一回合有 ×4，适合直接投掷。
- **夜晚或洞窟传说战**：黑暗球有 ×3.5，通常比高级球更合适。
- **长时间消耗战**：计时球经过 30 回合后达到 ×4，但需要足够耐久与恢复手段。
- **捕捉低等级目标**：巢穴球在等级很低时优于普通球；等级达到 30 后不再有加值。
- **补齐图鉴或收集异色**：目标已捕捉过时，重复球可发挥 ×3。
- **需要亲密度进化**：友友球直接把亲密度设为 200；豪华球则提高后续亲密度增长，两者效果不同。
- **必定获得的目标**：大师球全存档通常只有一个，建议留给游走宝可梦或自己最难捕捉的目标。
