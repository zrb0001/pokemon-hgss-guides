# 全技能机器列表

《宝可梦 心金·魂银》共有 **92 个技能机器（TM）与 8 个秘传机器（HM）**。本页按第四世代数据整理全部 100 个编号，并列出本作中的主要获取方式。

- TM 可以重复使用，使用后会教会一只兼容的宝可梦对应招式。
- HM 除了用于战斗，部分招式还能在获得相应徽章后解除地图障碍。
- 威力或命中显示为“—”时，表示该招式没有对应的固定数值；变化招式的实际效果请点击招式名称查看。
- 表中的抽奖与兑换都是可重复获取方式，单次剧情拾取或 NPC 赠送的机器通常每个存档只有一个。

## 获取建议

- **前期流程**：秘传机器优先随主线取得；满金百货和满金游戏城能补充不少实用 TM。
- **缺少游戏城代币**：部分招式另有地图拾取或百货购买途径，可对照表格选择，不必全部依赖代币兑换。
- **进入二周目后**：玉虹百货、玉虹游戏城和对战开拓区提供更多重复获取渠道，适合调整多只宝可梦的配招。
- **只找到表格中的一个地点**：部分机器本来就只能获得一次；表中分号隔开的是不同获取方式，不要求依次完成。
