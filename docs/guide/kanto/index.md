# 关都篇（二周目）流程攻略

关都地区的大部分道馆可以自由安排顺序。建议先完成无人发电厂事件，再按自己的队伍情况挑战各地道馆，最后集齐 16 枚徽章前往白银山。

## 枯叶市与发电厂事件

### 抵达关都

1. 在水流号上帮助船员寻找小女孩，随后抵达枯叶市。可直接挑战枯叶道馆，战胜马志士获得橙色徽章。
2. 枯叶道馆的机关需要连续在垃圾桶中找到两个开关，第二个开关位于第一个开关的相邻位置。
3. 马志士使用电属性宝可梦。地面属性免疫电属性招式，但要注意雷丘（ライチュウ / Raichu）等宝可梦掌握的其他属性攻击。

### 找回机械零件

1. 经 9、10 号道路前往无人发电厂，与所长对话，得知机械零件（きかいのぶひん / Machine Part）失窃。
2. 前往华蓝市，在华蓝道馆附近遇到火箭队成员。追向 24 号道路并与其战斗，取得零件藏匿位置的提示。
3. 返回华蓝道馆，在馆内的浮圈附近调查并找回机械零件。
4. 将零件交还无人发电厂所长，恢复关都地区供电。

恢复供电会影响华蓝道馆、磁浮列车、广播扩展频道与部分后续剧情，建议优先完成。

### 广播扩展频道与卡比兽

1. 前往紫苑镇广播塔，与相关人员对话获得扩展频道卡，使宝可装置能够收听关都地区的广播频道。
2. 在枯叶市东侧的 11 号道路找到卡比兽（カビゴン / Snorlax）。打开宝可装置广播，将频道手动移到最上方的宝可梦之笛频道，再与卡比兽对话即可触发战斗。
3. 捕捉或击败卡比兽后，可穿过地鼠洞穴前往深灰市方向。
4. 若要使用磁浮列车，还需要在金黄市帮助模仿少女找回丢失的玩偶。

水君（スイクン / Suicune）会在关都剧情中继续出现，最终在 25 号道路接受挑战；探索枯叶市、14 号道路与华蓝市时即可推进相关剧情。

## 华蓝、金黄、玉虹与浅红道馆

这四个道馆没有严格先后顺序，可利用飞翔按队伍情况安排挑战。

| 城市 | 馆主 | 属性 | 前置条件 |
| ---- | ---- | ---- | ---- |
| 华蓝市 | 小霞 | 水 | 恢复发电厂供电，并前往 25 号道路 |
| 金黄市 | 娜姿 | 超能力 | 无特殊前置 |
| 玉虹市 | 莉佳 | 草 | 无特殊前置 |
| 浅红市 | 阿杏 | 毒 | 无特殊前置 |

### 华蓝市

1. 完成发电厂事件后前往 25 号道路，在尽头的小屋外打断小霞的约会。
2. 返回华蓝道馆即可挑战小霞。她使用水属性宝可梦，草与电属性招式较容易取得优势。
3. 若已按剧情追踪水君，可在同一区域继续推进其定点遭遇。

### 金黄市

1. 挑战金黄道馆的娜姿。道馆由多个传送地板组成，可记录入口与房间的对应关系，减少重复传送。
2. 娜姿使用超能力属性宝可梦，恶、虫与幽灵属性招式有效，但需注意副属性和回复手段。
3. 道馆旁的格斗道场可自由挑战，不影响徽章收集；之后也是馆主再战的主要地点。
4. 在西尔佛公司可推进大吾相关剧情；获得丰缘最初的伙伴后，还能用佛烈托斯（フォレトス / Forretress）交换铁哑铃（ダンバル / Beldum）。
5. 在枯叶市宝可梦迷俱乐部取得模仿少女遗失的玩偶，再带回金黄市交还，可获得磁浮列车车票，并推进拉帝亚斯或拉帝欧斯的游走剧情。

### 玉虹市与浅红市

1. 玉虹道馆的莉佳使用草属性宝可梦，火、冰、飞行、虫与毒属性招式均有发挥空间。
2. 玉虹大厦可获得 GB 播放器（ＧＢプレイヤー / GB Sounds），用于切换复古音乐；这不是主线必要道具。
3. 浅红道馆的阿杏使用毒属性宝可梦，并设置了隐形墙。沿墙逐步确认通路即可到达馆主面前。
4. 超能力与地面属性招式适合应对毒属性队伍，同时应准备解毒与恢复道具。

## 深灰、红莲与常青道馆

### 深灰市

1. 穿过地鼠洞穴或经 2 号道路抵达深灰市，挑战小刚。岩石属性宝可梦普遍怕水与草属性招式，但大钢蛇（ハガネール / Steelix）具有钢属性，应分别判断弱点。
2. 在深灰市科学博物馆可复活第四世代化石；博物馆的后续剧情也与大吾和埋藏之塔有关。
3. 集齐 16 枚徽章后，可在深灰市与老人对话，获得当前版本尚未取得的封面神兽羽毛：心金为银色之羽（ぎんいろのはね / Silver Wing），魂银为虹色之羽（にじいろのはね / Rainbow Wing）。

### 红莲镇与双子岛

1. 红莲镇的大部分建筑已经被火山喷发摧毁，宝可梦中心可作为前往周边区域的恢复点。
2. 夏伯的道馆已经迁至双子岛。进入洞穴寻找夏伯并挑战，战胜后获得深红徽章。
3. 夏伯使用火属性宝可梦，水、地面与岩石属性招式有效；同时要留意日照对火属性招式和水属性招式的影响。
4. 双子岛深处也是急冻鸟（フリーザー / Articuno）的所在地，可在集齐 16 枚徽章后返回挑战。

### 常青市

1. 取得深灰、华蓝、枯叶、玉虹、浅红、金黄与深红七枚关都徽章后，青绿会返回常青道馆。
2. 青绿的队伍不局限于单一属性，挑战前应检查全队的等级、属性覆盖与恢复道具。
3. 战胜青绿后获得绿色徽章，至此集齐 16 枚徽章。
4. 前往真新镇与大木博士对话，获得秘传学习器 08 攀岩（ロッククライム / Rock Climb），并开放白银山。

## 白银山与赤红

1. 集齐 16 枚徽章后，先在真新镇与大木博士对话，再经 28 号道路进入白银山。
2. 山洞与外部岩壁需要攀岩，部分区域光线较暗。建议携带恢复、复活和解除异常状态的道具。
3. 沿山路到达山顶，与赤红对话开始战斗。他的队伍等级明显高于四天王，属性组合也很全面。
4. 战胜赤红后，主线流程正式完成。之后仍可继续完成全国图鉴、传说宝可梦与馆主再战。

## 赤红战后的赠送

| 赠送内容 | 获取方式 |
| ---- | ---- |
| 关都最初的伙伴 | 战胜赤红后，在真新镇大木研究所从妙蛙种子（フシギダネ / Bulbasaur）、小火龙（ヒトカゲ / Charmander）、杰尼龟（ゼニガメ / Squirtle）中选择一只 |
| 丰缘最初的伙伴 | 战胜赤红后，在金黄市西尔佛公司与大吾对话，从木守宫（キモリ / Treecko）、火稚鸡（アチャモ / Torchic）、水跃鱼（ミズゴロウ / Mudkip）中选择一只 |

## 埋藏之塔

1. 领取关都最初的伙伴后，前往宝可梦爷爷家领取宝珠：心金获得靛蓝色宝珠（あいいろのたま / Blue Orb），魂银获得朱红色宝珠（べにいろのたま / Red Orb）。
2. 前往 47 号道路的埋藏之塔。心金可挑战盖欧卡（カイオーガ / Kyogre），魂银可挑战固拉多（グラードン / Groudon），等级均为 50。
3. 要挑战烈空坐（レックウザ / Rayquaza），还需通过通信取得另一只版本限定的超古代宝可梦，且两只都必须源自《心金·魂银》。
4. 将盖欧卡与固拉多展示给大木博士，取得草绿色宝珠（もえぎいろのたま / Jade Orb），再回到埋藏之塔挑战烈空坐。

详细版本条件可查看[心金与魂银的区别](/guide/version-differences)。

## 重复挑战与收集

- 收集馆主电话号码，在指定时间预约后，到金黄市格斗道场进行更强阵容的再战。
- 再次挑战四天王与冠军，提升队伍等级。
- 完成狩猎地带模块、宝可计步器路线、阿露福遗迹与神都遗迹等收集和特殊剧情。
- 获取方式不明的宝可梦，可在[宝可梦图鉴](/data/pokedex)中查看版本、地点与特殊条件。
