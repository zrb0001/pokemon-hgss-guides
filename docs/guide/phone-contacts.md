# 所有可登记电话的人

《心金·魂银》的宝可装置没有电话号码数量上限，可以登记全部联系人。本页收录 **74 组登记条目**：16 位馆主、11 组剧情／设施人物与 47 组普通训练家。小响与琴音按主角性别二选一，因此单个存档最多登记 73 组。

:::tip[时间与再战规则]
- 早晨为 **04:00–09:59**，白天为 **10:00–19:59**，夜晚为 **20:00–次日 03:59**。
- 普通训练家需要先战胜，再在原地对话登记；到了再战时段，主动拨打电话即可预约。
- 馆主需要先取得电话号码，再在指定时段回电预约，然后前往金黄市格斗道场挑战。
- 道具、对话和培育信息类联系人不一定会提供再战；赠送道具通常需要反复联系，并非每次通话都有奖励。
:::
