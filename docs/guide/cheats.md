# 日版金手指

本页收录《宝可梦 心金·魂银》**日版**的 Action Replay DS（PAR）常用代码，包括道具、捕获、探索和培育功能。代码地址与游戏版本对应，**不能直接用于国际版、汉化版或修改版 ROM**。

:::danger[使用前备份存档]
金手指会修改游戏内存，可能造成死机、剧情无法推进或存档损坏。请先备份存档，一次只启用必要的代码；不要交换或上传来源不明、数据异常的宝可梦。
:::

## 版本与游戏 ID

| 版本 | 游戏代码 | 游戏 ID |
| ---- | ---- | ---- |
| 心金（日版） | `IPKJ` | `A587D7CD` |
| 魂银（日版） | `IPGJ` | `7387AC7F` |

输入到金手指设备或模拟器时，通常将二者连写为 `IPKJ-A587D7CD` 或 `IPGJ-7387AC7F`。如果设备识别出的 ID 不一致，应先确认版本，不要强行套用代码。

## 使用方法

1. 在金手指设备或模拟器的 **Action Replay／PAR** 功能中新建代码。
2. 选择一个代码块，完整复制其中的全部行，不要把多个代码混在同一个条目中。
3. 启用代码并进入游戏。标注按键的代码需要在游戏内按下对应组合键；未标注按键的代码通常持续生效。
4. 使用后关闭不再需要的代码，再保存游戏。出现异常时，不保存并重启游戏，关闭最近启用的代码。

代码中的字符均为十六进制，注意数字 `0` 与字母 `O`、数字 `1` 与字母 `I` 的区别。

## 常见问题

### 代码没有生效怎么办？

依次检查游戏是否为日版、设备识别的游戏 ID 是否一致、代码类型是否为 Action Replay／PAR，以及是否漏行或输入错误。标有 SELECT、L、R 等按键的代码，需要在进入游戏后操作，不是在金手指菜单中操作。

### 游戏卡住或黑屏怎么办？

不要保存，直接重启并关闭最近启用的代码。尝试一次只启用一个代码；背包补全、穿墙和持续修改能力或遭遇的代码尤其不宜混用。如果异常状态已经写入存档，需要恢复使用前的备份。

### 能否用于其他语言版本？

不能保证可用。不同版本的内存地址可能不同，即使游戏能够启动，也可能写入错误位置。应另找对应语言版本与游戏 ID 的代码，不要仅修改首行来强行适配。
