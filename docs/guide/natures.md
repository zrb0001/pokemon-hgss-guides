# 宝可梦性格

性格（せいかく / Nature）是宝可梦的固定特征，共有 **25 种**。其中 20 种会让一项能力提高 10%、另一项能力降低 10%，另外 5 种不改变能力。性格不会影响 HP、个体值或升级所需经验。

:::tip[心金·魂银的规则]
- 《心金·魂银》的能力界面会用**红色标出提高的能力、蓝色标出降低的能力**。
- 本作没有后世代的性格薄荷，已经确定的性格无法更改；进化与通信交换也不会改变性格。
- 性格还会影响口味偏好、宝可全能竞技赛的体能浮动，以及跟随宝可梦找到闪光树叶的地点。
:::

## 如何选择性格

没有适用于所有宝可梦的“最强性格”，应根据主要招式和队伍定位选择：

- **物理攻击手**：通常选择固执提高攻击，或爽朗提高速度；不需要的攻击或特攻是常见的降低项。
- **特殊攻击手**：通常选择内敛或胆小，并降低较少使用的攻击。
- **速度优先**：胆小、爽朗适合需要抢先出招的宝可梦，但要注意降低的是哪项防御或攻击能力。
- **低速队伍**：勇敢、冷静、自大、悠闲会降低速度，适合以低速利用戏法空间的队伍。
- **耐久定位**：大胆、淘气、温和、慎重可加强单项防御；不建议只看提高项，还要评估降低项是否会削弱另一项重要能力。

## 培育时遗传性格

让亲代携带不变之石（かわらずのいし / Everstone），可以影响蛋中宝可梦的性格：

- 父方或母方任意一方携带时，后代有 **50%** 概率继承携带者的性格。
- 双方都携带时，**25% 继承父方、25% 继承母方、50% 随机**。
- 第四世代中，如果亲代来自不同语言的游戏，不变之石的性格遗传效果不会生效。
- 第四世代中，性格在蛋出现时已经决定，因此应在蛋生成前让目标亲代携带不变之石。

不变之石可在孵出神奇蛋（ふしぎなタマゴ / Mystery Egg）后从空木博士处获得，也可在 25 号道路从正辉爷爷处获得；捕虫大赛二等奖和部分野生小拳石（イシツブテ / Geodude）、隆隆石（ゴローン / Graveler）也会提供。

## 用同步特性筛选性格

将拥有同步（シンクロ / Synchronize）特性的宝可梦放在队伍首位，遇到的野生宝可梦有 **50% 概率与其性格相同**，首位宝可梦即使濒死也仍然有效。

- 适用于多数普通野生遭遇与定点遭遇。
- 不适用于游走宝可梦、宝可计步器遭遇和礼物宝可梦。
- 只影响性格，不会同步属性、特性、个体值或异色状态。

## 性格与闪光树叶

跟随宝可梦能够找到闪光树叶的道路由性格决定。收集时不必让每只宝可梦在所有道路逐一尝试，可以先按性格缩小搜索范围。
