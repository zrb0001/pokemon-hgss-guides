# 心金与魂银的区别

《宝可梦 心金》与《宝可梦 魂银》的主线剧情、地图、道馆和绝大部分系统完全相同，主要区别在于剧情神兽的出现顺序，以及部分宝可梦的版本获得限制。

## 核心区别速览

| 项目 | 心金（HeartGold） | 魂银（SoulSilver） |
| ---- | ---- | ---- |
| 封面宝可梦 | 凤王（ホウオウ / Ho-Oh） | 洛奇亚（ルギア / Lugia） |
| 一周目剧情神兽 | 在铃铛塔挑战等级 45 的凤王 | 在漩涡岛挑战等级 45 的洛奇亚 |
| 剧情关键道具 | 虹色之羽（にじいろのはね / Rainbow Wing）与透明铃铛（とうめいなスズ / Clear Bell） | 银色之羽（ぎんいろのはね / Silver Wing）与海声铃铛（うみなりのスズ / Tidal Bell） |
| 二周目另一只封面神兽 | 在漩涡岛挑战等级 70 的洛奇亚 | 在铃铛塔挑战等级 70 的凤王 |
| 关都地区游走神兽 | 拉帝亚斯（ラティアス / Latias），等级 35 | 拉帝欧斯（ラティオス / Latios），等级 35 |
| 埋藏之塔神兽 | 盖欧卡（カイオーガ / Kyogre），等级 50 | 固拉多（グラードン / Groudon），等级 50 |
| 埋藏之塔所需宝珠 | 靛蓝色宝珠（あいいろのたま / Blue Orb） | 朱红色宝珠（べにいろのたま / Red Orb） |

:::tip[凤王与洛奇亚并非严格限定]
两个版本最终都能获得凤王和洛奇亚。一周目只能先挑战封面神兽；二周目在深灰市获得另一根羽毛后，便可挑战等级 70 的另一只。
:::

## 烈空坐为什么需要双版本

烈空坐（レックウザ / Rayquaza）在两个版本中都能挑战，但解锁条件需要盖欧卡和固拉多：

1. 在自己的版本中获得盖欧卡或固拉多。
2. 通过通信交换获得另一只，且两只都必须源自《心金·魂银》。
3. 将两只展示给大木博士，获得草绿色宝珠（もえぎいろのたま / Jade Orb）。
4. 前往 47 号道路的埋藏之塔，挑战等级 50 的烈空坐。

## 两个版本相同的内容

- 城都与关都的主线流程、16 个道馆和最终赤红战。
- 菊草叶（チコリータ / Chikorita）、火球鼠（ヒノアラシ / Cyndaquil）、小锯鳄（ワニノコ / Totodile）三只最初的伙伴。
- 宝可计步器、宝可全能竞技赛、狩猎地带和对战开拓区。
- 雷公（ライコウ / Raikou）、炎帝（エンテイ / Entei）、水君（スイクン / Suicune），以及关都地区其他传说宝可梦的主要获得方式。
- 全部 NPC 交换的宝可梦与地点；具体可查看[所有交换 NPC 一览](/guide/trades)。

## 版本选择建议

优先根据喜欢的封面神兽和限定宝可梦选择即可，两个版本没有剧情完整度或难度上的优劣：

- 喜欢凤王、卡蒂狗、天蝎、拉帝亚斯或盖欧卡，可选择《心金》。
- 喜欢洛奇亚、六尾、盔甲鸟、拉帝欧斯或固拉多，可选择《魂银》。
- 只想体验完整剧情，不必担心选错版本；想完成全国图鉴，则需要通信交换及与其他第四世代游戏联动。
