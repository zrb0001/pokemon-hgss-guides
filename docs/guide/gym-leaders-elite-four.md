# 四大天王与全部馆主资料

本篇汇总《宝可梦 心金·魂银》中城都、关都 16 位道馆馆主，以及石英联盟四天王和冠军渡的**初次挑战阵容**。等级、奖励与对战提示均按本作整理，不混入《金／银》《火红／叶绿》或再战数据。

:::tip[资料范围]
- 城都篇按主线挑战顺序排列，关都篇除常青道馆外可以自由安排顺序。
- 点击宝可梦和招式名称可查看本站图鉴或招式资料。
- 电话登记、格斗道场馆主再战及高等级阵容见[所有道馆馆主电话登记和再战方式](/guide/gym-rematches)。
:::

## 石英联盟四天王与冠军

集齐城都八枚徽章并穿过冠军之路后，可以在石英高原连续挑战四天王与冠军。挑战期间可以自由使用背包和更换宝可梦，但不能返回宝可梦中心，建议提前准备恢复、复活和解除异常状态的道具。
