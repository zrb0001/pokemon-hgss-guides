# 所有交换 NPC 一览

《宝可梦 心金·魂银》共有 10 组游戏内交换。下表分别列出普通 NPC 与特殊 NPC 的位置、交换内容、携带道具和解锁条件。

:::tip[交换须知]
- 每组交换在每个存档中只能进行一次。
- “玩家交出”指需要放入交换的宝可梦，“NPC 提供”指玩家获得的宝可梦。
- NPC 提供的宝可梦具有固定昵称和初训家，表中所列为交换时携带的道具。
:::
