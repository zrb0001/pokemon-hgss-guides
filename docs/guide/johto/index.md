# 城都篇（一周目）流程攻略

本篇按实际主线顺序整理，从若叶镇出发，到击败宝可梦联盟冠军为止。路线总览：**桔梗市 → 桧皮镇 → 满金市 → 缘朱市 → 湛蓝市／浅葱市 → 卡吉镇 → 满金广播塔 → 烟墨市 → 封面神兽 → 宝可梦联盟**。

## 若叶镇与桔梗市

### 主线流程

1. 在若叶镇的空木研究所选择菊草叶（チコリータ / Chikorita）、火球鼠（ヒノアラシ / Cyndaquil）或小锯鳄（ワニノコ / Totodile）之一，另外两只无法在本存档的常规流程中取得。
2. 离家后获得宝可装置（ポケギア / Pokégear）。沿 29 号道路向西到吉花市，再向北经过 30、31 号道路。
3. 在宝可梦爷爷家见到大木博士，获得宝可梦图鉴与神奇蛋（ふしぎなタマゴ / Mystery Egg）。
4. 返回吉花市时与劲敌战斗。回到若叶镇交付神奇蛋后，即可自由捕捉宝可梦并挑战道馆。
5. 再次沿 30、31 号道路前往桔梗市。先进入喇叭芽之塔，一路击败修行僧并在塔顶战胜长老。
6. 挑战桔梗道馆。馆主使用飞行属性宝可梦，岩石、电和冰属性招式较容易取得优势。
7. 获得飞行徽章后接到空木博士电话，在桔梗市宝可梦商店从助手处领回神奇蛋，之后可孵出波克比（トゲピー / Togepi）。

### 桔梗道馆

| 宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- |
| 波波（ポッポ / Pidgey） | 9 | 注意起风造成的持续伤害 |
| 比比鸟（ピジョン / Pidgeotto） | 13 | 等级较高，建议先提升全队等级 |

战胜阿速后获得飞行徽章与招式学习器 51 羽栖（はねやすめ / Roost）。徽章允许在地图上使用飞翔（そらをとぶ / Fly），但需先取得对应秘传学习器。

## 互连洞与桧皮镇

### 主线流程

1. 从桔梗市向南进入 32 号道路。沿途可挑战训练家，也可先进入阿露福遗迹完成拼图、收集未知图腾（アンノーン / Unown），但遗迹不是主线必经内容。
2. 通过互连洞抵达 33 号道路和桧皮镇。洞内需要冲浪（なみのり / Surf）的区域暂时无法探索，可留待之后返回。
3. 到桧皮镇西北的呆呆兽之井，与守井人对话后进入，击败火箭队成员。
4. 前往镇上的钢铁先生家，之后可以使用不同柑果制作精灵球。柑果每天可采集一次，不必一次全部交给钢铁先生。
5. 挑战桧皮道馆。馆主使用虫属性宝可梦，火、飞行和岩石属性招式有效。
6. 获得昆虫徽章后，进入桐树林帮助工匠找回两只大葱鸭（カモネギ / Farfetch’d），从后方接近并抓住它们。
7. 与工匠对话获得秘传学习器 01 居合劈（いあいぎり / Cut），让宝可梦学会后清除树林出口的树木。

### 桧皮道馆

| 宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- |
| 铁甲蛹（トランセル / Metapod） | 15 | 防御较高，持续输出即可 |
| 铁壳蛹（コクーン / Kakuna） | 15 | 用克制招式快速解决 |
| 飞天螳螂（ストライク / Scyther） | 17 | 速度快，连续使用虫属性招式时伤害会提高 |

战胜阿笔后获得昆虫徽章与招式学习器 89 急速折返（とんぼがえり / U-turn）。互连洞地下 2 层每周五会出现拉普拉斯（ラプラス / Lapras），需要冲浪，可在之后返回捕捉。

## 满金市与 36 号道路

### 主线流程

1. 从 34 号道路进入满金市。可在地下通道获得饰品盒，在自行车店免费获得自行车。
2. 进入广播塔回答前台问题，获得广播卡；广播卡之后可用于收听特殊频道和唤醒卡比兽（カビゴン / Snorlax）。
3. 挑战满金道馆。一般属性道馆的滚动攻击在连续命中后威力很高，建议在开战前恢复 HP，并准备催眠、麻痹等控制手段。
4. 战胜小茜后，她会暂时哭泣而不发放徽章；先离开道馆或与她再次对话，即可正常取得标准徽章。
5. 到道馆东北的花店领取喷壶（ゼニガメじょうろ / SquirtBottle）。
6. 可前往自然公园参加捕虫大赛，也可直接经 35 号道路、36 号道路前进。对 36 号道路的奇怪树木使用喷壶，与树才怪（ウソッキー / Sudowoodo）战斗。
7. 清除障碍后向东经过 37 号道路，抵达缘朱市。前往宝可梦中心可触发正辉剧情，之后在满金市正辉家领取伊布（イーブイ / Eevee）。

### 满金道馆

| 宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- |
| 皮皮（ピッピ / Clefairy） | 17 | 注意迷人造成的行动限制 |
| 大奶罐（ミルタンク / Miltank） | 19 | 滚动会逐渐增强，尽量快速压低 HP |

战胜小茜后获得标准徽章与招式学习器 45 迷人（メロメロ / Attract）。标准徽章允许在地图上使用怪力（かいりき / Strength）。树才怪只有一只，之后仍可通过孵蛋获得盆才怪（ウソハチ / Bonsly）。

## 缘朱市、浅葱市与湛蓝市

### 缘朱市与烧焦塔

1. 进入缘朱市西北的烧焦塔，与劲敌交战。前往地下层靠近雷公（ライコウ / Raikou）、炎帝（エンテイ / Entei）与水君（スイクン / Suicune），触发它们离开的剧情。
2. 雷公与炎帝从此开始在城都地区游走；水君仍会在固定地点出现，需要继续追踪。
3. 挑战缘朱道馆。幽灵属性宝可梦不受一般与格斗属性招式影响，恶属性招式更容易取得优势。
4. 战胜松叶后获得幽灵徽章与招式学习器 30 暗影球（シャドーボール / Shadow Ball），并可在地图上使用冲浪。
5. 在缘朱市宝可梦中心附近的民居取得秘传学习器 03 冲浪，随后从浅葱市西南方海面出发。

### 浅葱市与湛蓝市

1. 初次抵达浅葱市时，先到灯塔与阿蜜对话。她需要秘传药治疗电龙（デンリュウ / Ampharos），此时不会接受道馆挑战。
2. 经 40、41 号水路前往湛蓝市。漩涡岛内部可稍后探索，主线先向西北前进。
3. 在湛蓝市药房取得秘传药（ひでんのくすり / SecretPotion），再挑战湛蓝道馆。
4. 战胜阿四后获得风暴徽章；离开道馆与门口的女性对话，取得秘传学习器 02 飞翔，即可快速返回浅葱市。
5. 到浅葱灯塔顶层交付秘传药，再返回浅葱道馆挑战阿蜜。
6. 获得钢铁徽章后，从缘朱市东侧的 42 号道路前往卡吉镇。

### 道馆战

| 道馆 | 主要宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- | ---- |
| 缘朱道馆·松叶 | 耿鬼（ゲンガー / Gengar） | 25 | 注意催眠术与食梦的组合 |
| 湛蓝道馆·阿四 | 火爆猴（オコリザル / Primeape） | 29 | 使用飞行或超能力属性招式 |
| 湛蓝道馆·阿四 | 蚊香泳士（ニョロボン / Poliwrath） | 31 | 同时具有水与格斗属性 |
| 浅葱道馆·阿蜜 | 大钢蛇（ハガネール / Steelix） | 35 | 防御很高，优先考虑特殊攻击 |

风暴徽章附带招式学习器 01 真气拳（きあいパンチ / Focus Punch），钢铁徽章附带招式学习器 23 铁尾（アイアンテール / Iron Tail）。

## 卡吉镇与愤怒之湖

1. 从缘朱市向东进入 42 号道路，可使用居合劈打开捷径；穿过擂钵山或沿道路继续向东，抵达卡吉镇。
2. 卡吉道馆最初无法挑战。先向北经过 43 号道路进入愤怒之湖，在湖中央与红色暴鲤龙（ギャラドス / Gyarados）战斗。
3. 捕捉或击败红色暴鲤龙后获得红色鳞片（あかいウロコ / Red Scale），可在宝可梦爷爷家交换学习装置（がくしゅうそうち / Exp. Share）。
4. 在湖边与渡对话，返回卡吉镇杂货店，从秘密入口进入火箭队基地。
5. 深入基地，击败火箭队干部并解除发电装置。完成后渡会赠送秘传学习器 06 旋涡（うずしお / Whirlpool）。
6. 返回卡吉道馆挑战柳伯。冰属性招式克制草、地面、飞行与龙属性，但水属性宝可梦能抵抗冰招式，不宜只按单一属性判断。

| 宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- |
| 小海狮（パウワウ / Seel） | 30 | 水属性，可用草或电属性招式应对 |
| 白海狮（ジュゴン / Dewgong） | 32 | 水／冰属性，可用电或格斗招式应对 |
| 长毛猪（イノムー / Piloswine） | 34 | 冰／地面属性，水系招式效果较好 |

战胜柳伯后获得冰川徽章与招式学习器 07 冰雹（あられ / Hail），并可在地图上使用旋涡。

## 满金广播塔

1. 获得冰川徽章后前往满金广播塔。击败塔内火箭队成员，并在顶层揭穿假台长。
2. 取得地下钥匙后前往满金地下通道，打开仓库门，继续深入并救出真正的广播塔台长。
3. 返回广播塔，一路击败干部与最终首领，解除火箭队对广播的控制。
4. 与台长对话：心金获得虹色之羽（にじいろのはね / Rainbow Wing），魂银获得银色之羽（ぎんいろのはね / Silver Wing）。这是后续封面神兽剧情的必要道具。

广播塔剧情未完成时，44 号道路与烟墨市方向会受到阻碍，不能直接跳往烟墨市。

## 烟墨市与龙穴

1. 从卡吉镇向东经过 44 号道路，再穿过冰雪小径。部分冰面会强制滑行，需要观察落脚点规划路线。
2. 进入烟墨市后挑战烟墨道馆。龙属性只被冰与龙属性克制，但哈克龙并非龙属性最终形态，组队时也要考虑其掌握的其他属性招式。
3. 战胜小椿后，她不会立即发放徽章。进入道馆后方的龙穴，使用冲浪与旋涡到达龙祠。
4. 在龙祠回答长老的提问。以理解、尊重与爱护宝可梦为核心的回答可完成试炼，并获得升龙徽章。
5. 离开龙穴后再次与长老对话，可领取迷你龙（ミニリュウ / Dratini）；回答符合要求时，它会掌握神速（しんそく / ExtremeSpeed）。
6. 返回烟墨市后接到空木博士电话，回若叶镇可领取大师球（マスターボール / Master Ball）。

| 宝可梦 | 等级 | 建议 |
| ---- | ---- | ---- |
| 哈克龙（ハクリュー / Dragonair）×3 | 38 | 注意电磁波与不同属性的攻击招式 |
| 刺龙王（キングドラ / Kingdra） | 41 | 水／龙属性，冰属性不再具有克制优势 |

战胜小椿并完成龙穴试炼后获得升龙徽章与招式学习器 59 龙之波动（りゅうのはどう / Dragon Pulse）。

## 缘朱舞场与封面神兽

1. 前往缘朱市舞场，连续挑战五位和服女孩。她们分别使用伊布的不同进化形，战斗之间可在场外恢复。
2. 心金获得透明铃铛（とうめいなスズ / Clear Bell），魂银获得海声铃铛（うみなりのスズ / Tidal Bell）。
3. **心金**：带着虹色之羽与透明铃铛进入铃铛塔，在塔顶挑战等级 45 的凤王（ホウオウ / Ho-Oh）。
4. **魂银**：带着银色之羽与海声铃铛前往漩涡岛，在深处挑战等级 45 的洛奇亚（ルギア / Lugia）。
5. 捕捉或击败封面神兽后，主线仍可继续。若意外击败，之后再次挑战宝可梦联盟可让部分定点传说宝可梦重新出现。

## 冠军之路与宝可梦联盟

1. 从若叶镇东侧使用冲浪进入 27 号道路，经过都城瀑布与 26 号道路，抵达联盟入口。
2. 检查八枚城都徽章后进入冠军之路。洞内需要使用冲浪、怪力与碎岩（いわくだき / Rock Smash），建议提前准备好对应宝可梦。
3. 在接近出口的位置与劲敌战斗。此后离开洞穴，便到达宝可梦联盟大楼。
4. 在宝可梦中心恢复，并补充恢复 HP、解除异常状态与复活用道具。进入四天王房间后不能自由返回商店，但每场战斗之间仍可打开背包治疗。

| 顺序 | 对手 | 主要属性 | 应对思路 |
| ---- | ---- | ---- | ---- |
| 1 | 一树 | 超能力 | 恶、虫与幽灵属性招式有效，注意不同宝可梦的副属性 |
| 2 | 阿桔 | 毒 | 超能力与地面属性招式有效，减少中毒造成的消耗 |
| 3 | 希巴 | 格斗 | 飞行与超能力属性招式有效，注意岩石属性攻击 |
| 4 | 梨花 | 恶 | 格斗与虫属性招式有效，注意超能力属性宝可梦的副属性 |
| 5 | 渡 | 龙／飞行 | 冰属性可覆盖多只宝可梦，留意快龙（カイリュー / Dragonite）的耐久与回复 |

战胜渡后与空木博士进入殿堂，记录队伍并观看结局。读取通关存档后，图鉴升级为全国图鉴，并可获得浅葱市前往枯叶市的船票。前往浅葱市码头乘坐水流号（S.S. Aqua），完成船上寻找小女孩的事件后抵达关都。

全国图鉴还会解锁新的广播遭遇、狩猎地带区域、馆主电话再战与更多传说宝可梦剧情。继续阅读[关都篇（二周目）流程攻略](/guide/kanto/)。
