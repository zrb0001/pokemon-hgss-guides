# 隐藏要素

《宝可梦 心金·魂银》在主流程与常规收集之外，还藏有多项不会主动提示的玩法。本页介绍跟随互动、隐藏房间、特殊广播和活动剧情，不重复版本差异、交换 NPC、星期家族与特性列表的内容。

## 闪光树叶与叶冠

跟随的宝可梦有时能在草丛中找到**闪光树叶（かがやくはっぱ / Shiny Leaf）**。这是纯收集要素，不会提高宝可梦的对战能力。

1. 让目标宝可梦排在队伍首位，在草丛附近与它对话。
2. 如果它出现感叹号、左右摇摆并冒出绿色音符，就会找到一片闪光树叶。
3. 可能出现树叶的道路由宝可梦的**性格**决定；即使地点正确，也需要反复对话尝试。
4. 同一只宝可梦累计找到 **5 片**后，向若叶镇的小响／琴音展示，可换成**叶冠（リーフクラウン / Leaf Crown）**，并增加训练家卡上的一颗星。

随着持有树叶增多，继续寻找的概率会下降。想收集叶冠时，不必每只宝可梦都去所有道路尝试，应先根据性格缩小范围。

## GB Sounds 复古音乐

集齐关都地区的 8 枚徽章后，前往玉虹市宝可梦中心旁边的玉虹大厦，在 3 楼与 GAME FREAK 的音效设计师对话，可获得 **GB 播放器（ＧＢプレイヤー / GB Sounds）**。

- 在重要道具栏中打开或关闭，即可切换复古音乐。
- 不仅地图与战斗音乐会变化，部分本作新增场景和设施的音乐也有对应的 Game Boy 风格版本。
- 广播节目不受此开关影响，适合与原版《金·银》的配乐对比欣赏。

## 阿露福遗迹的隐藏房间

四个拼图房间除了逐步解锁未知图腾（アンノーン / Unown）的不同字母，还各有一间隐藏房。调查拼图后的文字墙，并满足对应条件即可开启。

| 拼图 | 隐藏房开启条件 | 主要奖励 |
| ---- | ---- | ---- |
| 化石盔（カブト / Kabuto） | 在房间中使用穿洞绳（あなぬけのヒモ / Escape Rope） | 树果、元气粉与万能粉 |
| 菊石兽（オムナイト / Omanyte） | 背包中有水之石，并在文字墙前选择使用；不会消耗水之石 | 星星沙子、星星碎片、苹野果与神秘水滴 |
| 化石翼龙（プテラ / Aerodactyl） | 让宝可梦在文字墙前使用闪光（フラッシュ / Flash） | 能量之根、万能粉、月之石与橙橙果 |
| 凤王（ホウオウ / Ho-Oh） | 让凤王排在队伍首位，成为跟随宝可梦后调查文字墙 | 苹野果、复活草、木炭与生命宝珠 |

补充要点：

- 后三个房间需要从互连洞的不同出口绕行，部分路线需要冲浪或怪力。
- 捕捉全部 26 个字母的未知图腾，并开启四间隐藏房后，可继续完成未知图腾图鉴的相关剧情，解锁 **？与！** 两种形态。
- 在遗迹内收听 13.5 频道的神秘电波，有助于遭遇尚未捕捉的已解锁字母。

## 全国图鉴后的广播遭遇

获得全国图鉴后，宝可梦齿轮的“宝可梦进行曲”频道会在固定星期播放特殊音乐，让部分其他地区的宝可梦加入当前地图的随机遇敌表。

| 星期 | 广播 | 可吸引的宝可梦示例 |
| ---- | ---- | ---- |
| 星期三 | 丰缘之声（Hoenn Sound） | 蛇纹熊（ジグザグマ / Zigzagoon）、幕下力士（マクノシタ / Makuhita）、阿勃梭鲁（アブソル / Absol） |
| 星期四 | 神奥之声（Sinnoh Sound） | 小猫怪（コリンク / Shinx）、泳圈鼬（ブイゼル / Buizel）、铜镜怪（ドーミラー / Bronzor） |

特殊遭遇只出现在原本就支持该广播遭遇的地图，并非全区所有宝可梦都会出现。**每场战斗结束后需要重新打开广播**，再继续寻找目标。

## 神都遗迹与神话宝可梦

将以“命运的相遇”标记的阿尔宙斯（アルセウス / Arceus）放在队伍首位，前往阿露福遗迹，可触发前往神都遗迹（シントいせき / Sinjoh Ruins）的特殊剧情。

- 在遗迹内会遇到竹兰（シロナ / Cynthia），并进入三幻舞台。
- 可以从帝牙卢卡、帕路奇亚和骑拉帝纳中选择一只，观看其诞生剧情。
- 获得的宝可梦为 **等级 1**，并分别携带金刚宝珠、白玉宝珠或白金宝珠。

:::warning[活动限定内容]
该剧情需要特定的活动阿尔宙斯，不能依靠普通单机流程直接解锁，也不要求先获得全国图鉴。它与埋藏之塔的盖欧卡、固拉多和烈空坐剧情是不同事件。
:::

## 馆主电话与再战

获得全国图鉴后，16 位馆主不再只是一次性的道馆对手：

1. 在各自指定的地点、时间或条件下取得馆主的电话号码。
2. 在该馆主对应的预约时段通过宝可梦齿轮拨打电话。
3. 前往金黄市的格斗道场，即可进行更高等级的再战。

每位馆主的电话取得方式和预约时段都不同，例如阿蜜需要在每天 13:00–13:59 到浅葱市餐厅与她对话，小椿则需要在完成龙穴的双打剧情后，于早晨到龙穴与她对话。再战阵容会使用第四世代的新进化形，强度明显高于初次挑战。完整名单见[所有道馆馆主电话登记和再战方式](/guide/gym-rematches)。

## 每周五的拉普拉斯

在互连洞地下 2 层南部水面，每周五会出现等级 20 的**拉普拉斯（ラプラス / Lapras）**。需要冲浪才能到达，属于地图上的固定目标而非普通随机遇敌。捕捉或击败后，可以在下一个星期五再次遇到。

这只拉普拉斯与星期家族无关，也不消耗其他每周事件的触发次数，适合在一周目中期作为稳定的水／冰属性战力。
