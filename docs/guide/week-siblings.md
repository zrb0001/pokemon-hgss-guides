# 星期家族

星期家族（曜日兄弟 / Week Siblings）是分散在城都各地的七名 NPC，每人只在固定星期出现。首次对话可获得提升对应属性招式威力的道具，见过全部七人后还能领取每周奖章。

## 出现条件与规则

- 需要先获得**飞翼徽章**，星期家族成员才会出现。
- 每人只在自己的对应星期出现，时间由 Nintendo DS 的系统日期决定。
- 每人赠送的属性道具在每个存档中只能领取一次。
- 26 号道路的星期家族住宅内留有七人的出现星期与地点，可随时查看。

## 每周奖章

在至少见过全部七名成员各一次后，再次于对应星期拜访，即可获得上表所列的奖章：

- 每位成员每周只能赠送一枚奖章。
- 下周同一时间可以再次领取，适合为多只宝可梦收集同类奖章。
- 领取属性道具不是领取奖章的前提；只要七人都已见过即可。

其他固定星期活动可查看首页的[每周事件时间表](/#weekly-events)。
