# 所有道馆馆主电话登记和再战方式

《心金·魂银》的 16 位道馆馆主都可以在二周目再次挑战。玩家需要先找到离开道馆的馆主并登记电话号码，再在指定时段主动回电预约，最后前往金黄市格斗道场完成再战。馆主初战阵容及四天王资料见[四大天王与全部馆主资料](/guide/gym-leaders-elite-four)。

## 再战流程与共同条件

1. **登入名人堂并获得全国图鉴**：此后才能开始登记馆主电话号码。
2. **集齐 16 枚徽章**：战胜青绿并获得绿色徽章后，才能正式预约馆主再战。
3. **登记电话号码**：按下表指定的星期、时间、地点与特殊条件找到馆主；阿四和青绿的号码需要向其他 NPC 索取。
4. **主动回电预约**：在馆主对应的预约时段，通过宝可装置的电话功能主动联系馆主。
5. **前往格斗道场**：预约成功后，到金黄市道馆旁的格斗道场与馆主对话，即可进行再战。

:::tip[时间与预约规则]
- 早晨为 **04:00–09:59**，白天为 **10:00–19:59**，夜晚为 **20:00–次日 03:59**。
- 预约成功后，馆主会一直在格斗道场等待，直到完成对战，不必赶在同一个预约时段内到场。
- 在同一预约时段内可以反复预约，并非每周只能再战一次。重复预约前，需要先离开格斗道场以及馆主所在区域，再拨打电话。
:::

:::warning[特殊登记注意事项]
- 奈奈美每天只能在 15:00–15:59 按摩一次，因此青绿的号码至少需要分 7 天完成前置。
- 马志士的登记条件不是单纯持有皮卡丘；需要让皮卡丘排在队伍首位，使其跟随在主角身后。
- 小霞与马志士分别涉及水君和闪电鸟剧情，若到达指定地点后没有见到馆主，应先检查对应传说宝可梦事件是否完成。
:::
