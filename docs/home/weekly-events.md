# 每周事件时间表

《心金·魂银》的许多活动会按照 Nintendo DS 的系统星期与时间来刷新。本页汇总可重复参加的固定星期事件，并区分**全天开放**与**限定时段**，方便按当天日期安排流程。

:::tip[阅读方式]
- 早晨为 **04:00–09:59**，白天为 **10:00–19:59**，夜晚为 **20:00–次日 03:59**；“全天”指当天 00:00–23:59。
- “登记”指一次性取得馆主电话号码，“预约”指主动回电安排再战。馆主的地点、条件和阵容见[馆主电话登记与再战](/guide/gym-rematches)。
- 普通训练家均指主动回电预约再战，英文名与[所有可登记电话的人](/guide/phone-contacts)保持一致；详细登记地点和电话奖励可在该页查询。
- 每日大量出现的具体宝可梦与地点、一次性剧情和拍照地点不列入固定周历。
:::
